# Terraform Homelab

Hands-on Terraform learning project focused on infrastructure automation,
state management, modules, and enterprise Terraform practices.

## Structure

### 01-basics

Terraform fundamentals:

- Providers and resources
- Plan and apply
- Terraform state
- Variables and outputs
- Workspaces
- Data sources
- Locals

### 02-modules

More advanced Terraform concepts:

- Child modules
- for_each and count
- Conditional resources
- Resource dependencies
- Lifecycle rules
- Local backend
- State operations and recovery

## Environment

- RHEL 9
- Terraform 1.16.x
- Git
- VS Code
- HashiCorp Local Provider

## Notes

Terraform state files, local provider data, variable files containing
environment-specific values, and generated lab resources are excluded
from Git.
